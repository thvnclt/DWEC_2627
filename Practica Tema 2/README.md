## Descripción del Proyecto
Es una entraga práctica del Tema2. Se han desarrollado dos páginas web interactivas utilizando HTML5, Bootstrap 5 y JavaScript para analizar los motores de ejecución y realizar pruebas de eventos y consola.

---

## Estructura del Proyecto
- `index.html`: Comparativa de motores JavaScript y análisis del ecosistema Chromium.
- `interaccion.html`: Interfaz interactiva para pruebas de eventos y consola.
- `app.js`: Script de JavaScript con la lógica de las funciones e interacción.
- `capturas/`: Carpeta con las evidencias en imagen de las pruebas realizadas.
